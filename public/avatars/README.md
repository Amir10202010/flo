# Avatar images

These avatars (`dana.jpg`, `sofia.jpg`, `karim.jpg`, `marco.jpg`) are **AI-generated
faces** produced by a StyleGAN model (via thispersondoesnotexist.com). They depict
**no real person** — every face is synthetic — so there are no model-release,
likeness, or publicity-rights concerns when pairing them with the marketing
testimonials. They are downscaled to 128×128 and used purely as placeholder avatars.

Replace with real customer photos (with written consent) once we have them.
